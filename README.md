# Comprehensive Autoimmune Disorder Data Analysis & Visualization

Project Overview: 
This project focuses on analyzing and visualizing patterns, trends, and clinical characteristics within a comprehensive autoimmune disorder dataset. Developed for the **Data Science Visualization (24ADI204)** course, this repository aims to uncover key insights using exploratory data analysis (EDA) and interactive visualizations.

---

Dataset Information: 
* **File Name:** `Final_Balanced_Autoimmune_Disorder_Dataset.csv`
* **Domain:** Healthcare / Clinical Data Science
* **Description:** A balanced dataset containing clinical, demographic, and diagnostic indicators related to various autoimmune disorders.

---

Objectives: 
* Conduct **Exploratory Data Analysis (EDA)** to understand feature distributions and correlations.
* Create intuitive and insightful **data visualizations** (charts, heatmaps, distribution plots) to illustrate key clinical findings.
* Identify patterns across demographic groups, diagnostic tests, and disease severity.

---
Tools & Libraries Used: 
* **Programming Language:** Python 3.x
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`, `plotly`
* **Environment:** Jupyter Notebook / Google Colab
